# pqax.tools

The web reader of PQAX, the file format for the storage footprint of Parquet and Delta tables. Open a `.pqax` file, or a `.vpax` file that embeds one, in the browser and see where the storage goes: nothing is uploaded.

The site is built from the packages `@pqax/pqax` and `@pqax/views` of the [pqax-org/pqax](https://github.com/pqax-org/pqax) repository, where the format, the conformance kit, and the implementations live. The first version of this site comes with release 0.2.0 of those packages; until then the page is served at [pqax.org/tools](https://pqax.org/tools/).
